# Star Global Realtors - Case Study

Luxury real estate platform with an administrative dashboard, user-linked management, blog maintenance, and hierarchical content structure.

**Preview:** https://starglobalrealtors-nuggu9xis-agen-cia-f1368c33.vercel.app/

## Overview

Star Global Realtors is a premium real estate web platform designed to present high-end properties with a professional and elegant digital experience.

The project includes an administrative structure for managing content, users, blog updates, and hierarchical information related to the real estate business.
